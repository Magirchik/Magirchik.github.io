# Magirchik.github.io

Личный сайт на обычных HTML, CSS и JavaScript. Сборка и установка пакетов не нужны.

## Где что менять

- `index.html` — тексты, ссылки, разделы и кнопки.
- `styles.css` — внешний вид. Цвета и ширина страницы заданы в `:root` в начале файла.
- `script.js` — поведение страницы. Сначала настройки цветов, затем кнопки 1–5, дождь и эффекты профилей. Подключение событий находится в конце файла.

Чтобы посмотреть сайт, откройте `index.html` в браузере.

## Как устроены эффекты

У эффектов есть функции запуска и остановки: например, `startFalling()` и `stopFalling()`. Исходные стили, тексты и места блоков сохраняются перед изменениями, чтобы «ОТМЕНА» и Escape могли восстановить страницу. Общая отмена — `stopAllEffects()`.

- Кнопка 1 меняет оформление.
- Кнопка 2 роняет элементы страницы.
- Кнопка 3 запускает взрыв с аватарами.
- Кнопка 4 перемешивает надписи, блоки и действия кнопок, меняет цвета, размеры, шрифты, отступы, сетку, границы и эффекты. Все случайные стили собраны в `shufflePageStyles()`.
- Кнопка 5 засасывает интерфейс по спирали в чёрную дыру.

Фразы и ASCII-арты для дождя находятся в массиве `rainWords`. `drawRain()` последовательно создаёт слова, обновляет движение, проверяет столкновения и рисует кадр. Размеры текста кешируются, чтобы не измерять их заново при каждом появлении.
